# Shreshth Agarwal — Personal Portfolio A responsive personal developer portfolio built with **HTML, CSS, and a little JavaScript**. The project is intentionally kept in a single HTML file, making it beginner-friendly and easy to customize. ## Features - Dark navy and orange colour scheme - Responsive layout for desktop, tablet, and mobile - About, Skills, Projects, and Contact sections - Mobile-friendly navigation menu - Smooth scrolling between sections - Project cards with technology tags - Email contact link - No frameworks or external dependencies required ## Project Structure ```text portfolio/ ├── index.html └── README.md ``` ## Run Locally 1. Download or clone this project. 2. Open the project folder. 3. Double-click `index.html` to open it in your browser. You can also open the folder in Visual Studio Code and use the Live Server extension while editing. ## Customize the Website Open `index.html` in a code editor and update: - **Name:** Search for `Shreshth Agarwal`. - **Email:** Search for `shreshthagarwal17@gmail.com`. - **About:** Edit the paragraphs in the About section to describe yourself. - **Skills:** Replace the sample skill badges with skills you know. - **Projects:** Replace the three sample project cards with your own projects. - **Social links:** Replace the GitHub and LinkedIn URLs with your profile URLs. The current project cards are examples. Update them so they accurately describe work you have completed. ## Publish for Free with GitHub Pages 1. Sign in to [GitHub](https://github.com/) or create a free account. 2. Create a **public** repository. You can name it `shreshthagarwal.github.io` (or use your own GitHub username in the repository name). 3. Upload `index.html` and `README.md` to the repository's root folder. 4. Open the repository's **Settings** tab. 5. Select **Pages** from the sidebar. 6. Under **Build and deployment**, choose **Deploy from a branch**. 7. Select the `main` branch and `/ (root)` folder, then save. 8. Wait for GitHub Pages to publish the site. Your URL will usually be: `https://YOUR-GITHUB-USERNAME.github.io/` For detailed instructions, see the [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart). ## Technologies Used - HTML5 - CSS3 - JavaScript ## Contact **Shreshth Agarwal** Email: [shreshthagarwal17@gmail.com](mailto:shreshthagarwal17@gmail.com) --- Made with HTML, CSS, and curiosity.
